# Інструмент перевірки коректності парсингу резюме в ATS

Відкритий інструмент для кандидатів, що дозволяє перевірити коректність зчитування тексту резюме парсерами ATS.

### Очікувані ефекти
- Кандидат бачить результат розбору до подання, тож нечитний файл можна відрізнити від бідного
- mech.ats_parser_extraction_failure переходить із невидимого в перевірне — на боці кандидата

### Вимірювання
- `parser_extraction_error_rate`
- `ingestion_pass_rate`
