# Verification Discrepancy Disclosure and Reconciliation Window

Classify every mandatory check in advance as reconcilable by document or disqualifying, release the disputed field and both values to the candidate on the day the result returns, and hold the offer open for a stated window with a revised start date.

### Expected Effects
- M-021 arrives as a named field with two values and a named closing document, instead of as a hold with no stated cause
- B-011 contains the reconciliation step: the window, the evidence that closes each check and who reviews it are set before the check runs rather than after it returns
- Which findings a document can close and which end the process is a published classification rather than a per-file decision

### Measurements
- `verification_hold_duration_days`
- `discrepancy_reconciliation_rate`
- `disclosed_finding_ratio`
