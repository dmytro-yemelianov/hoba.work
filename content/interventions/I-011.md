# Screening Note Bound to Observations and Disposition Codes

Restrict the screening note to the requirement, what the record shows and the surface opened, and close it with a fixed disposition code — including a referral to levelling for profiles above the graded band.

### Expected Effects
- The forecast mech.experience_age_grading_mismatch is recorded as has no field to sit in: the note takes the requirement, what the record shows, and a disposition code
- mech.portfolio_work_artifact_misinterpretation becomes checkable: the surface that was opened is recorded next to the note written from it, and the application form asks which surface that should be
- A profile above the graded band leaves bar.inbound_screening_triage with a routing code rather than a pass at screen

### Measurements
- `screening_note_field_completeness`
- `above_grid_referral_rate`
- `artifact_surface_recorded_rate`
