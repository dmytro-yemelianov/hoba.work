# The path as it is supposed to run

This is the canonical path: one opening, from a real need to a decision the
candidate can act on. It is written as a machine because that is how the rest of
the registry is written, and because a commitment that cannot be expressed as a
state and a guard is usually not a commitment.

**It is a construct, not a description of anybody.** No employer runs exactly
this. It is assembled from the things employers already say they do — bands on
postings, rubrics agreed before interviews, decisions inside a stated window,
postings taken down when a search ends — and put in one order so that the rest
of the atlas has something to be measured against.

That is the whole point of it. A barrier is not simply a gate: a gate is normal
and this path has fourteen of them. A barrier is the point at which one of these
commitments stops being kept. `deviations` on each state names which ones, which
is why every barrier in the registry appears on exactly one state of this path
and every mechanism on at least one.

Two things this path deliberately does **not** treat as deviations. A decline is
not a deviation — most candidates are declined, and a path that could only end
in a hire would be a fantasy rather than a standard. A closed search is not a
deviation either; needs change and budgets go. What makes both of them part of
the path rather than departures from it is that they arrive, they say what
happened, and they arrive in time to be useful.
