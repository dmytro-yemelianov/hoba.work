# Employment Gap Penalty Loop

An employment gap triggers automated downranking (M-011), which pushes the profile below keyword and qualification filters (M-008); fewer interview invitations lengthen the gap, which in turn strengthens the downranking.

### Cycle Dynamics
This causal loop reinforces mechanisms across iterations:
- `M-011` amplifies `M-008`
- `M-008` amplifies `M-011`
