# Requisition Approval & Public Posting

The gate that exists before any candidate does: headcount is authorized, the job description is written, and the requisition is published (or quietly kept open) on careers pages and job boards.

### Pass Condition
An approved requisition with a written job description is published against real, funded headcount.
